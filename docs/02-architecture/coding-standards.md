# Coding Standards

## PHP

- usare namespace coerenti
- usare prepared statements
- evitare SQL nei controller
- mantenere metodi piccoli
- validare input prima di scrivere su DB

## JavaScript

- un file JS per pagina
- usare `fetchJSON`
- mostrare toast in basso a sinistra
- non duplicare business logic critica
- eseguire `node --check` dopo modifiche

## UI

- usare AdminLTE
- usare DataTables per griglie
- usare modali Bootstrap per CRUD
