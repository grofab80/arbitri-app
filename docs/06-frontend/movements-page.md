# Movements Page

File:

- `admin/movements.php`
- `admin/js/movements.js`

## Funzioni

- lista movimenti
- KPI movimenti
- creazione/modifica/eliminazione admin
- filtri e dipendenze categoria
- griglia allineata allo standard DataTables dell'app: date/importi/azioni
  centrati, testi a sinistra, azioni con larghezza dedicata

## Permessi Azioni

- `movements.create`: mostra il pulsante nuovo e abilita creazione
- `movements.edit`: mostra il pulsante modifica
- `movements.delete`: mostra il pulsante elimina, riservato ad admin
