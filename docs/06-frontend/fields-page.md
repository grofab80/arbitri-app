# Fields Page / Stadi

File:

- `admin/fields.php`
- `admin/js/fields.js`

## Funzioni

- lista stadi
- creazione/modifica/eliminazione
- indirizzo strutturato con via, citta, provincia, CAP e nazione
- geocodifica manuale
- abilitazioni calcio a 11, 7 e 5
- stato attivo/non attivo

## Note

La pagina usa DataTables, modale Bootstrap e toast.

Il bottone "Verifica indirizzo" e disponibile in modifica e salva le coordinate
dello stadio tramite endpoint backend.
