# Matches Page

File:

- `admin/matches.php`
- `admin/js/matches.js`

## Funzioni

- lista partite
- creazione/modifica/eliminazione
- selezione competizione e squadre
- gestione difficolta partita da 1 a 5
- filtro automatico delle squadre casa/trasferta per evitare duplicati
- assegnazione arbitro
- select arbitro con rating a stelle
- select arbitro con distanza dallo stadio quando le coordinate sono disponibili
- assegnazione stadio
- risultato regolare o a tavolino
- griglia con data, ora, giornata, difficolta, competizione, squadre, arbitro,
  risultato e stato

## Permessi Azioni

- `matches.create`: mostra il pulsante nuovo e abilita creazione
- `matches.edit`: mostra il pulsante modifica
- `matches.delete`: mostra il pulsante elimina
