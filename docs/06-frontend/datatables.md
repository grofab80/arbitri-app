# DataTables

Le pagine con griglie devono usare DataTables.

## Convenzioni

- `pageLength: 10`
- `ordering: false`, salvo necessita specifiche
- lingua italiana
- azioni in ultima colonna
- header colonne centrati orizzontalmente e verticalmente
- celle sempre centrate verticalmente
- celle testo allineate a sinistra
- celle data/ora, numeriche, flag, immagini e azioni centrate orizzontalmente
