# Product Overview

Arbitri App e una web application gestionale per associazioni sportive.

Il progetto copre due aree principali:

- gestione sportiva: stagioni, competizioni, squadre, arbitri, partite e risultati
- gestione amministrativa: movimenti economici, categorie contabili, entrate, uscite e KPI

L'applicazione e in sviluppo incrementale. Le scelte architetturali devono quindi privilegiare compatibilita, refactoring graduale e mantenimento del funzionamento esistente.

## Stack

- Backend: PHP custom MVC
- Frontend: PHP server-rendered pages, JavaScript vanilla, jQuery
- UI: AdminLTE, Bootstrap, Font Awesome
- Tabelle: DataTables
- Messaggi: jquery-toast-plugin
- Database: MariaDB/MySQL
- Autenticazione: JWT
