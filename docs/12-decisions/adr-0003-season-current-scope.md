# ADR 0003: Current Season Scope

## Stato

Accettata

## Contesto

L'app lavora prevalentemente sulla stagione sportiva corrente.

## Decisione

Movimenti, dashboard e viste operative usano la stagione corrente come scope principale.

## Conseguenze

- UI piu semplice
- filtri storici potranno essere aggiunti in futuro
- serve una sola stagione corrente
