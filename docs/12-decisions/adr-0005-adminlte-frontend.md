# ADR 0005: AdminLTE Frontend

## Stato

Accettata

## Contesto

Serve un'interfaccia admin coerente e rapida da sviluppare.

## Decisione

Usare AdminLTE, Bootstrap, Font Awesome, DataTables e toast.

## Conseguenze

- UI coerente
- pagine CRUD veloci da creare
- evitare design custom non necessario
