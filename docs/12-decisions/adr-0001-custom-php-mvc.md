# ADR 0001: Custom PHP MVC

## Stato

Accettata

## Contesto

Il progetto usa PHP senza framework full-stack.

## Decisione

Mantenere architettura MVC custom con controller, model, validator e service.

## Conseguenze

- maggiore controllo
- responsabilita architetturali da documentare bene
- necessita di disciplina su controller sottili e model dedicati
