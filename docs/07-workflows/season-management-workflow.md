# Season Management Workflow

1. Admin apre pagina stagioni.
2. Crea nuova stagione.
3. La nuova stagione nasce in stato `nuovo`.
4. Admin avvia la stagione impostandola `in_corso`.
5. Il sistema chiude eventuali altre stagioni in corso.
6. Le viste operative usano la stagione in corso.
7. Admin puo chiudere una stagione dopo conferma esplicita.
8. La chiusura genera o aggiorna lo snapshot ufficiale del bilancio.
